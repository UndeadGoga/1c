# Архитектурное описание отказоустойчивого кластера 1С

## 1. Цели и задачи

**Цель:** обеспечить непрерывную доступность информационных баз 1С:Предприятие 8.3 Community Edition при отказе любого из компонентов инфраструктуры.

**Задачи:**
- Реализовать отказоустойчивую инфраструктуру серверов 1С с балансировкой нагрузки.
- Настроить потоковую репликацию PostgreSQL 16 (Primary → Standby).
- Автоматизировать развёртывание средствами Docker Compose, Terraform и Ansible.
- Обеспечить мониторинг ключевых метрик и систему оповещений.
- Разработать сценарии резервного копирования и восстановления (Disaster Recovery).
- Реализовать нагрузочное тестирование и проверку отказоустойчивости.

## 2. Высокоуровневая архитектура

### 2.1. Уровни отказоустойчивости

| Уровень | Компонент | Механизм отказоустойчивости | ПО |
|---------|-----------|----------------------------|-----|
| L4 | Пользовательский доступ | HAProxy (TCP-балансировка) | HAProxy (GPL v2) |
| L7 | Прикладные серверы 1С | 2+ сервера 1С Community Edition | 1С Community (бесплатно) |
| БД | PostgreSQL | Потоковая репликация + ручной failover | PostgreSQL 16 (официальный образ) |
| Хранение | Диски БД | Docker volumes / LVM / RAID | — |
| Мониторинг | Prometheus/Grafana | Репликация TSDB, backup метрик | Open Source |

### 2.2. Схема компонентов

```
                    [ Пользователи / Тонкие клиенты ]
                                │
                    [ HAProxy (Active) ]
                    │                    │
        [ 1С:Сервер #1 ]          [ 1С:Сервер #2 ]
        (Ubuntu 22.04)            (Ubuntu 22.04)
        ragent:1540               ragent:1540
        rmngr:1541                rmngr:1541
        rphost:1560-1591          rphost:1560-1591
                    │                    │
                    └────────┬───────────┘
                             │
                [ PostgreSQL 16 Primary :5432 ]
                    │  (потоковая репликация WAL)
                [ PostgreSQL 16 Replica :5432 ]
                             │
                    [ /backup — бэкапы ]
```

## 3. Детализация компонентов

### 3.1. Кластер 1С:Предприятие 8.3 Community Edition

**Сервер 1С (ragent + rmngr + rphost):**
- Управляет списком информационных баз.
- Обеспечивает лицензирование клиентов (в Community — до 5 сеансов).
- В Docker-контейнере запускается `ragent`, который порождает `rmngr` и `rphost`.
- **Особенность сборки:** интерактивный установщик 1С не поддерживает silent-режим. Поэтому 1С устанавливается на хосте вручную, а затем `/opt/1cv8` копируется в образ через `COPY`.

**Порты:**
- 1540 — агент сервера (ragent)
- 1541 — менеджер кластера (rmngr)
- 1560–1591 — рабочие процессы (rphost)
- 1545 — RAS (удалённое администрирование)

### 3.2. PostgreSQL 16 с репликацией (официальный образ)

**Primary (Master):**
- Принимает запись и чтение.
- Настроен `wal_level = replica`, `archive_mode = on`.
- Отправляет WAL на Standby через потоковую репликацию.
- Используется официальный Docker-образ `postgres:16` (не кастомная сборка от 1С, т.к. она требует устаревших зависимостей: `libssl1.1`, `libicu66`, `libldap-2.4-2`).
- Локаль: `C.UTF-8` (совместимо с контейнером).

**Standby (Replica):**
- Инициализируется через `pg_basebackup` с Primary.
- Работает в режиме `hot_standby = on`.
- Готов стать Primary в случае failover.

**Failover:**
- Ручной/скриптовый failover через `pg_ctl promote`.
- Для production рекомендуется Patroni или repmgr (бесплатные).

### 3.3. HAProxy

HAProxy балансирует TCP-соединения клиентов 1С между серверами.

- **Порт 1540** — ragent (roundrobin, server-2 в backup)
- **Порт 1541** — rmngr (roundrobin, server-2 в backup)
- **Порт 1545** — RAS (roundrobin)
- **Порт 8404** — статистика HAProxy (HTTP)

```
listen 1c_ragent
  bind *:1540
  mode tcp
  option tcp-check
  balance roundrobin
  server 1c-server-1 1c-server-1:1540 check inter 2000 fall 3 rise 2
  server 1c-server-2 1c-server-2:1540 check inter 2000 fall 3 rise 2 backup
```

### 3.4. Мониторинг (Prometheus + Grafana + Alertmanager)

**Сбор метрик:**
- `node_exporter` — метрики ОС (CPU, RAM, диски, сеть).
- `postgres_exporter` — метрики PostgreSQL (connections, replication lag).
- `blackbox_exporter` — проверка доступности TCP-портов 1С, PostgreSQL.
- `cadvisor` — метрики Docker-контейнеров.

**Алерты:**
- Высокая загрузка CPU/RAM.
- Replication lag > 100 MB.
- Падение процессов ragent.
- Отсутствие резервного копирования > 25 часов.
- PostgreSQL Primary недоступен.

## 6. Масштабирование

- **Горизонтальное:** добавление рабочих серверов 1С (в рамках лицензии) и реплик PostgreSQL.
- **Вертикальное:** увеличение CPU/RAM для процессов rphost.
- **Бесплатные альтернативы платным компонентам:**
  - Вместо коммерческого балансировщика — HAProxy
  - Вместо коммерческого мониторинга — Prometheus + Grafana
  - Вместо коммерческого backup — pg_basebackup + shell-скрипты
